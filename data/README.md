# Данные

RecSys будет использовать MovieLens 100K: https://grouplens.org/datasets/movielens/100k/.
Исходные рейтинги не публикуются повторно; скрипт загрузки добавляется при реализации эксперимента.
Учебные инциденты и их тестовая разметка будут храниться отдельно и явно помечаться как синтетические.
