# Работа над проектом

- Читать README.md, docs/stack.md, docs/requirements.md и docs/NEXT_STEPS.md.
- Агентная система и RecSys — самостоятельные части. Не связывать их в один workflow.
- Основная ветка содержит подготовленную основу; разработку продолжать в oleg/implementation.
- Сохранять сырые реальные результаты. Не заменять модельные ошибки успешными заглушками.
- Отчёты оформлять чёрно-белыми: чёрные заголовки, без синих акцентов; проверять DOCX и PDF после рендера.
- Unit-тесты транспорта используют моки; настоящие вызовы LLM проверяются отдельным scripts/smoke_llms.py.
- make smoke может завершиться с кодом 1 из-за обнаруженной галлюцинации Qwen. Не ослаблять сценарий ради зелёного статуса.
- Не публиковать веса, MovieLens, .env, токены, внутренние логи с приватными данными или окружения.
- Перед коммитом запускать make check; при изменении моделей/адаптера — реальный smoke.
- Не заявлять наличие workflow, HSTU, trained scorer, evals или dashboards, пока соответствующий запуск не выполнен.
- Исходные материалы и архивный непроверенный прототип находятся вне этого репозитория; не копировать их целиком.
