# Реальные прогоны разработки

В каждой папке с временем UTC лежат полные ответы настоящих локальных моделей, trajectory,
OpenTelemetry spans и сводка сравнения с ручной разметкой evals/scenarios.json.
Пять искусственных случаев используются при разработке, не являются holdout и не доказывают
общую точность или безопасность. Исходные неудачные запуски не перезаписываются.

Папка initial-attempt содержит первый неудачный полный разбор БД и диагностические запросы
при выборе ролей. Это не отдельный успешный benchmark. В частности:

- LFM в роли аналитика ошибочно выбрала application_error; валидатор отклонил результат.
- Уточнение runbook, названий метаданных и короткие коды причин проверялись на этих же данных.
- Qwen 0.8B приняла ложную гипотезу о релизе: role-diagnostic-final.json.
- После этой ошибки выбран более крупный валидатор Qwen 4B; его отдельная проверка находится в results/validator/.

Актуальные идентификаторы полных прогонов и измерения приведены в docs/readiness.md.
Для повторения: make models-start; make scenarios. Обычные пользовательские запуски сохраняются
в results/live/ и не публикуются автоматически.
