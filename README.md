## Быстрый запуск на имеющемся Mac Intel

Нужны Python 3.12 и Git. Команды выполняются из корня репозитория.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements/macos-intel-py312.lock
.venv/bin/python -m pip install --no-deps -e .
make check
make assets
make models-start
make smoke
make api
```

API: http://127.0.0.1:8140/docs ; здоровье: `/health`; модели: `/models`; доступность моделей: `/readiness`;
метрики API: `/metrics`. Полноценного endpoint расследования пока нет.

`make smoke` делает 9 реальных запросов к 3 моделям и записывает исходные ответы. При ошибке поведения
возвращает ненулевой код: на первом прогоне Qwen выдумала причину без доказательств, остальные проверки прошли.
Это обнаруженное ограничение, а не тест, который следует ослаблять ради зелёного статуса.

```sh
make models-stop
```

Для нового окружения Linux устанавливайте core через `pip install -e '.[dev]'`, затем CPU PyTorch и ML extras
по [инструкции инфраструктуры](infra/README.md). Lock-файл Mac не предназначен для Linux.

## Выбранные компоненты

| Задача | Выбор |
|---|---|
| Оркестрация | LangGraph, Python 3.12 |
| API и контракт | FastAPI, Pydantic, HTTPX |
| Локальные LLM | llama.cpp b12359, GGUF, CPU, контекст 4096 |
| Быстрые шаги | Qwen3.5 0.8B Q4_0 |
| Кандидат в аналитики | LFM2.5 1.2B Instruct Q8_0 |
| Кандидат в валидаторы | SmolLM3 3B Q4_K_M, другое семейство |
| Jev-like | Независимый `jevlike`, отдельный обучаемый option scorer |
| Память | Состояние графа, SQLite checkpointer, долгосрочные факты с FTS5 и TTL |
| Изоляция | Отдельная Linux VM под Lima VZ, отдельный пользователь агента |
| Наблюдаемость | OpenTelemetry, Phoenix; Prometheus/Grafana для ресурсов и алертов |
| RecSys | PyTorch, MovieLens 100K, небольшая HSTU и baseline первого блока |
| Проверки | pytest, Ruff, GitHub Actions; реальные модельные проверки отдельно |

Основания и ограничения: [выбор стека](docs/stack.md). Источники моделей и SHA-256: [manifest](config/model-manifest.json).

Три коротких вопроса на модель подтверждают работоспособность интерфейса, но недостаточны для оценки интеллекта
или надёжности. Настоящие evals и сравнение всего workflow будут отдельными результатами.

Веса, данные MovieLens, окружения и временные логи не входят в Git. Для модели Liquid сохраняется отдельная лицензия.
Помощь ИИ используется при подготовке и разработке; результаты должны проверяться реальными запусками,
а автор должен понимать и самостоятельно объяснять работу на защите.
