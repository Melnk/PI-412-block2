КФУ ИТИС, группа 11-412. Индивидуальная работа: **IncidentLab** и отдельное исследование **RecSys HSTU**.

**Стадия: реализован первый связанный сценарий IncidentLab.** Исследователь выбирает источники,

## Запуск на Mac Intel

Нужны Python 3.12, Git и около 7 GB для четырёх GGUF, дополнительно место для окружения и движка.
Команды выполняются из корня репозитория.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements/macos-intel-py312.lock
.venv/bin/python -m pip install --no-deps -e .
make check
make assets
make models-start
make api
```

Открыть **http://127.0.0.1:8140**, выбрать инцидент и нажать «Разобрать инцидент».
Для демонстрации используются локальные LLM на CPU; API-ключи не нужны.

В другом терминале:

```sh
make demo        # реальный checkout-01 через всех агентов
make scenarios   # пять реальных интеграционных сценариев
make smoke       # 12 коротких вопросов четырём моделям
```

`make smoke` возвращает ненулевой код при ошибке модели. В начальном прогоне Qwen 0.8B выдумала причину
при отсутствии доказательств. Сырые неудачи сохранены; тесты не ослабляются ради зелёного статуса.
Пять сценариев используются при разработке и не считаются независимым benchmark интеллекта.

После работы остановить API через Ctrl+C, модели — `make models-stop`.
Для Linux: установить core через `pip install -e '.[dev]'`, собрать движок по [инструкции](infra/README.md).
Lock-файл Mac не предназначен для Linux. ML extras для первого сценария не обязательны.

## Компоненты

| Задача | Реализованный выбор |
|---|---|
| Оркестрация | LangGraph, Python 3.12, ограниченный цикл проверки |
| API и контракт | FastAPI, Pydantic, HTTPX |
| Исследователь | LFM2.5 1.2B Instruct Q8_0 |
| Аналитик | SmolLM3 3B Q4_K_M |
| Валидатор | Qwen3.5 4B Q4_K_M, другое семейство |
| Дополнительный кандидат | Qwen3.5 0.8B Q4_0, сохранён для сравнения |
| Inference | llama.cpp b12359, CPU, контекст 4096, loopback |
| Данные | Пять явно синтетических инцидентов; разметка вне tools |
| Инструменты | Только чтение метрик, логов и релизов из разрешённых файлов |
| Результат | JSON, цитаты, следующий шаг, статус отказа, траектория |
| Наблюдаемость | Реальные OTel spans в JSONL, Prometheus counters и CPU/RAM API |
| Проверки | pytest, Ruff, GitHub Actions; реальные LLM-прогоны отдельно |

API: `/docs`, `/health`, `/models`, `/readiness`, `/incidents`, `POST /investigations`,
`GET /investigations/{run_id}`, `/metrics`.

Источники, ревизии и SHA-256: [manifest](config/model-manifest.json).
Роли и локальные адреса: [models.json](config/models.json). Аргументы выбора: [стек](docs/stack.md).
Данные и веса, окружение и runtime не включены в Git. Лицензия Liquid сохранена отдельно.

Помощь ИИ используется при подготовке и разработке; результаты проверяются реальными запусками,
а автор должен понимать и самостоятельно объяснять код на защите.
