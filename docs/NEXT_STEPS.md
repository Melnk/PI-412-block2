# Дальнейшая работа второго блока

## Подготовка и первый сценарий

- [x] Индивидуальное ТЗ, проверка требований и исследование источников.
- [x] Отдельный репозиторий и структура независимых IncidentLab и RecSys.
- [x] Python-окружение, зависимости, Ruff, pytest и CI.
- [x] Конфигурация моделей, проверка GGUF и движка, первоначальные реальные вызовы трёх LLM.
- [x] Пять синтетических инцидентов: БД, релиз, недостаточно данных, injection, ошибка приложения.
- [x] Разрешённые инструменты чтения с проверкой пути, происхождения, размера и времени.
- [x] Связанный LangGraph: выбор инструмента → анализ → проверка ссылок → независимый валидатор.
- [x] Ограниченные повторы, бюджеты, разделение ошибок и недостатка данных.
- [x] Сохранение результата, сырых ответов, одного trace, spans, траектории и токенов.
- [x] Веб-интерфейс и API, интеграционные проверки с тестовым gateway.

Фактические реальные модельные прогоны и их ограничения см. в docs/readiness.md.
Текущие проверки не заменяют полный независимый benchmark всего проекта.

## Следующий проход

1. Jev-like scorer: независимые шаблоны train/val/test, обучение, вероятности, calibration, fallback.
2. Три слоя памяти: рабочее состояние, история и долгосрочные проверенные факты; TTL, обновление и отзыв устаревших фактов.
3. Запуск агента пользователем incidentlab внутри отдельной VM; egress и негативные тесты доступа.
4. Phoenix, Prometheus/Grafana: заполненные dashboards с token usage, latency, CPU/RAM и рабочий алерт.
5. Отдельно RecSys: временной split MovieLens, четыре baseline, маленькая HSTU, три seed и ablation.
6. Полные evals агентов, одиночной LLM и версии без валидатора; исследование ошибок и уязвимостей RecSys.
7. Семь C4 и несколько sequence diagrams, итоговый PDF с доказательствами, чистый запуск и репетиция.

Агент и RecSys остаются самостоятельными частями. Обычный venv не считается изоляцией.
На текущем этапе inference работает на хосте Mac; созданная VM ещё не является готовым защищённым runtime.
